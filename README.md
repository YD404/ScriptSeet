# ScriptSheet

動画撮影や制作現場で使用する、シンプルで使いやすいブラウザベースのスクリプトシート（記録表）エディタです。
インストール不要で、ブラウザがあればどこでも動作します。

## 特徴

*   **自動保存機能**: 入力したデータはブラウザのローカルストレージに自動的に保存されるため、誤ってタブを閉じても安心です。
*   **スマート入力**: 行を追加する際、前の行の情報を元にカット番号(C)、テイク数(T)、クリップ名を自動的にインクリメント・推測して入力します。
*   **マルチデイ対応**: 撮影日ごとにタブを分けて管理できます。
*   **印刷最適化**: 現場での配布や保管用に、A4用紙などで見やすく印刷できるレイアウトに対応しています。
*   **データ管理**: データをJSONファイルとして書き出し（保存）、読み込み（復元）が可能です。

## 使い方

### 1. 起動方法
`index.html` を各種モダンブラウザ（Chrome, Edge, Safariなど）で開くだけで使用できます。

### 2. 基本操作
*   **行の追加**: 画面右下の `+` ボタンを押すと、記録用の行が追加されます。
*   **場所の追加**: `場` ボタンを押すと、シーンの場所（ロケーション）を区切る行が追加されます。
*   **判定の入力**: 「判定」列をクリックすると、`OK` -> `Keep` -> `NG` -> `空` の順にステータスが切り替わります。
*   **削除**: 各行の左側にある `×` ボタンで行を削除できます。

### 3. ヘッダー・設定
*   **タイトル・日付**: 画面上部の入力欄で作品名や日付を設定できます。
*   **日（Day）の切り替え**: ドロップダウンメニューで撮影日を切り替えたり、`+日` `-日` ボタンで日を追加・削除できます。

### 4. 保存・印刷
*   **印刷**: 「印刷」ボタンをクリックすると印刷プレビューが開きます。
*   **保存**: 「保存」ボタンで現在の全データをJSONファイルとしてダウンロードします。
*   **読込**: 「読込」ボタンから、以前保存したJSONファイルを読み込んで復元します。
*   **削除**: 「削除」ボタンで全てのデータをクリアします（確認ダイアログが出ます）。

## 動作環境
HTML5/CSS3/JavaScriptが動作する一般的なWebブラウザ。
